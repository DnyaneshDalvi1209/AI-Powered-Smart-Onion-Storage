# AI-Powered-Smart-Onion-Storage System
A smart onion storage solution designed to reduce post-harvest losses and extend shelf life through real-time temperature and humidity monitoring, automated ventilation, ESP32-based local control, AI-powered spoilage risk analysis, and remote monitoring. The system provides scalable, low-cost, and energy-efficient storage management for farmers.
